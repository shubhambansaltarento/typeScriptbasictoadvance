Combining Everything

For an e-commerce TypeScript project, you could combine everything from this series like this:

type ProductStatus =
  | "ACTIVE"
  | "OUT_OF_STOCK"
  | "DISCONTINUED";

interface Product {
  readonly id: number;
  name: string;
  price: number;
  description?: string;
  status: ProductStatus;
}

type ProductWithStock = Product & { stock: number };

type ProductResponse =
  | { success: true; data: ProductWithStock[] }
  | { success: false; error: string };

interface ProductCache {
  [productId: string]: ProductWithStock;
}

function handleProducts(response: ProductResponse): void {
  if (response.success) {
    response.data.forEach(product => console.log(product.name));
  } else {
    console.error(response.error);
  }
}

This single example contains:

type              → ProductStatus / ProductResponse
interface         → Product / ProductCache
union             → ProductStatus / ProductResponse
intersection      → ProductWithStock
literal           → "ACTIVE", "OUT_OF_STOCK"
optional          → description?
readonly          → id
index signature   → ProductCache
void              → handleProducts()

And you can add function assertNever(value: never): never { ... } for exhaustive handling of ProductStatus in a switch.

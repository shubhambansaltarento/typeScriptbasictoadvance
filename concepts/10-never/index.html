never

never represents a value that will never exist.

Most commonly, a function that never successfully returns:

// Infinite loop
function infiniteLoop(): never {
  while (true) {
    console.log("running");
  }
}

// Function that always throws
function throwError(message: string): never {
  throw new Error(message);
}

There is no return - the function starts, throws, and never returns.

Very important use: exhaustive checking

type Status = "pending" | "success" | "failed";

function handleStatus(status: Status) {
  switch (status) {
    case "pending": return "Waiting";
    case "success": return "Done";
    case "failed":  return "Failed";
    default: return assertNever(status);
  }
}

function assertNever(value: never): never {
  throw new Error(`Unexpected value: ${value}`);
}

Now if you later add "cancelled" to Status without adding a matching case, TypeScript will tell you that your switch isn't exhaustive - because status in the default branch no longer narrows to never. This is a very useful senior-level TypeScript technique.

Intersection Types

Intersection means: combine multiple types together.

type User = { id: number; name: string };
type Employee = { department: string };

type EmployeeUser = User & Employee;

const employee: EmployeeUser = {
  id: 1,
  name: "Shubham",
  department: "Engineering"
};

Think of it as:

User
   +
Employee
   ↓
EmployeeUser

Common real-world usage

Suppose your backend returns a Product, and the frontend needs to add its own UI state:

type Product = { id: number; name: string; price: number };
type ProductUIState = { isSelected: boolean; isLoading: boolean };

type ProductViewModel = Product & ProductUIState;

Now a single value carries both the server data and the UI-only fields.

Union vs Intersection

Remember this:

  • A | B means A OR B - satisfies one side or the other.
  • A & B means A AND B - must satisfy both at once.

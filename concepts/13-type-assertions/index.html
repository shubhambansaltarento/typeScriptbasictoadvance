Type Assertions

A type assertion tells TypeScript: I know more about this value than you do.

const value = something as string;
const input = document.querySelector("#username");
const username = input as HTMLInputElement;

console.log(username.value);
// "I know this DOM element is an HTMLInputElement."

Important: assertions don't convert at runtime

const value = "123" as unknown as number;
// does NOT turn "123" into 123 - it's still "123"

If you want conversion:

const value = Number("123");

Assertion vs validation

Bad, if you don't actually know the response shape:

const user = response as User;

Better for untrusted external data:

API
 ↓
unknown
 ↓
validate
 ↓
User

Libraries such as Zod are commonly used for this pattern.

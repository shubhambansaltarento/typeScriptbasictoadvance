Literal Types

Instead of saying let status: string, you can restrict a value to a fixed set of exact values: 

type Status =
  | "pending"
  | "processing"
  | "shipped"
  | "delivered";

let status: Status;

status = "pending";    // ✅
status = "shipped";    // ✅
status = "cancelled";  // ❌

This is extremely useful for state machines and API contracts.

Example

type PaymentStatus =
  | "PENDING"
  | "SUCCESS"
  | "FAILED";

function processPayment(status: PaymentStatus) {
  if (status === "SUCCESS") {
    console.log("Payment completed");
  }
}

You get autocomplete and compile-time safety - a typo like "SUCESS" fails to compile.

Literal + union = powerful

type HTTPMethod =
  | "GET"
  | "POST"
  | "PUT"
  | "PATCH"
  | "DELETE";

Much safer than a plain method: string.

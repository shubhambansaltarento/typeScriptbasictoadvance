Optional Properties

Use ? when a property may not exist.

interface User {
  id: number;
  name: string;
  phone?: string;
}

const user1: User = { id: 1, name: "Shubham" };
const user2: User = { id: 2, name: "Rahul", phone: "9999999999" };

Both are valid. But user1.phone is considered string | undefined, so:

if (user1.phone) {
  console.log(user1.phone.toUpperCase());
}

Important distinction

Optional (phone?: string) means the property may be missing. Whereas phone: string | undefined means the property exists, but its value can be undefined. This distinction becomes important when using strict TypeScript settings.

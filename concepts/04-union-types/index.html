Union Types

A union means: this value can be one of several types.

type ID = string | number;

let id: ID;
id = 100;       // ✅
id = "USR-100"; // ✅
id = true;      // ❌

Real API example

Unions shine when a value can genuinely take more than one shape - like an API response that either succeeded or failed: 

type ApiResponse =
  | { success: true; data: Product[] }
  | { success: false; error: string };

function handleResponse(response: ApiResponse) {
  if (response.success) {
    console.log(response.data);
  } else {
    console.log(response.error);
  }
}

This is extremely important in TypeScript. You're telling the compiler: there are multiple possible shapes, and you need to figure out which one we're dealing with. Checking response.success inside the if is what lets TypeScript narrow response to the right branch - this leads directly to type narrowing.

Tuples

A tuple is an array with a fixed structure and known positions.

let user: [number, string];

user = [1, "Shubham"]; // ✅
user = ["Shubham", 1]; // ❌

Because index 0 must be a number and index 1 must be a string.

Example

type ProductRecord = [number, string, number];

const product: ProductRecord = [101, "Laptop", 75000];
// meaning: [productId, productName, price]

Optional tuple elements

type User = [number, string, string?];

const user1: User = [1, "Shubham"];
const user2: User = [1, "Shubham", "Bangalore"];

Rest elements

type Coordinates = [number, number, ...number[]];

const point: Coordinates = [10, 20, 30, 40];

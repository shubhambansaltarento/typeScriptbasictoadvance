unknown

unknown means: I don't know what this value is yet.

let value: unknown;

value = 10;
value = "hello";
value = true; // all valid

But you cannot directly use it:

console.log(value.toUpperCase());
// ❌ Object is of type 'unknown'

You have to narrow it first:

if (typeof value === "string") {
  console.log(value.toUpperCase());
}

Why is unknown better than any?

let data: any;
data.foo.bar.baz(); // TypeScript doesn't complain

let data2: unknown;
data2.foo.bar.baz(); // ❌ TypeScript forces you to verify the type

API example

async function getData(): Promise<unknown> {
  const response = await fetch("/api/products");
  return response.json();
}

const data = await getData();
if (Array.isArray(data)) {
  console.log(data);
}

Mental model

  • any → "Trust me."
  • unknown → "Prove it."

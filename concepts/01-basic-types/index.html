Basic Types

TypeScript adds type annotations on top of every value JavaScript already has. Writing let name: string tells the compiler exactly what name is allowed to hold, so assigning something of the wrong shape becomes a compile-time error instead of a bug you find at runtime.

The primitives

  • string, number, boolean - the everyday JavaScript primitives.
  • bigint - for integers larger than number can safely represent, written with an n suffix like 100n.
  • null and undefined - each is both a value and its own type.
  • symbol - a guaranteed-unique value, often used as a hidden/collision-free object key.

Why annotate at all?

TypeScript can usually infer these types from the initializer (let age = 33 is already known to be a number). Writing the annotation explicitly is most useful for function parameters, return types, and variables that start empty - anywhere the compiler has nothing to infer from yet.

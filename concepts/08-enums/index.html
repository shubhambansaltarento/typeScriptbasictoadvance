Enums

Enums let you define a set of named constants.

enum OrderStatus {
  Pending,
  Processing,
  Shipped,
  Delivered
}

const status: OrderStatus = OrderStatus.Pending;

By default the members are numbered from 0:

OrderStatus.Pending    // 0
OrderStatus.Processing // 1
OrderStatus.Shipped    // 2
OrderStatus.Delivered  // 3

You can specify the values explicitly instead:

enum OrderStatus {
  Pending = "PENDING",
  Processing = "PROCESSING",
  Shipped = "SHIPPED",
  Delivered = "DELIVERED"
}

Modern TypeScript consideration

For many application cases, this:

type OrderStatus =
  | "PENDING"
  | "PROCESSING"
  | "SHIPPED"
  | "DELIVERED";

is preferable to an enum because it doesn't create a runtime enum object - it's erased entirely at compile time. You should understand enums for interviews, but don't automatically reach for them.
